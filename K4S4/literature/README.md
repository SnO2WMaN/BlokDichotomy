# Literature for the K4 and S4 investigation

Store useful papers, books, and research notes here. Both the user and agent may
add material. The agent may search the internet and download relevant, accessible
sources; if access is unavailable, ask the user for a copy or relevant excerpt.

For each source, record its filename, authors, title, publication details, source
URL when available, and pages or results relevant to the investigation. Distinguish
published results from informal notes and conjectures.

Source files are git-ignored by default. This index can be tracked; copyrighted
documents should remain local and should be cited without reproducing long passages.
